# Digital-Wedding-Invite-Portfolio
Portfolio showcase for my digital responsive wedding invitation web application built with Next.js, React, TypeScript, 
and Tailwind CSS, with a component-based UI using shadcn/ui and Radix UI, deployed on Vercel.

# Live Demo
https://ourweddinginvitation.shwetsh.xyz/

# About the Project
This project is a personalized digital wedding invitation that provides guests with an interactive experience rather than a traditional static invitation.

The application opens with an interactive wedding invitation experience, allowing visitors to interact with the invitation seal and explore the wedding information.

## Features
* Interactive wedding invitation experience
* Wedding-themed visual design
* Responsive web experience
* Interactive invitation opening
* Personalized wedding content
* Deployed and accessible through a public web URL
